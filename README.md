# 《量化投资精要》

**作者：** 揖光尘  
**发布：** 2026年9月1日  
**协议：** MIT

《量化投资精要》是一部面向现代量化研究与投资工程的体系化教程。全书从金融理论、数据和统计基础出发，覆盖股票、ETF、LOF、债券、可转债、商品、期货、期权、外汇与 REITs，进一步讨论多因子、机器学习、择时、CTA、套利、波动率、资产配置、组合优化、风险控制和实盘工程。

本书也将人工智能原生研究方式纳入量化投资框架，介绍端到端模型、大语言模型（LLM）、智能体（Agent）和 Vibe Coding，重点讨论它们如何服务于信息提取、研究设计、代码生成、回测验证、风险审查和研究工作流自动化。

## 本书特点

- **完整的资产与工具谱系：** 不只讨论股票和商品，也覆盖 ETF、LOF、债券、可转债、期权、外汇及另类资产。
- **完整的策略谱系：** 从多因子、择时和趋势跟踪，延伸到套利、相对价值、事件驱动、波动率和多策略组合。
- **研究与工程并重：** 将数据治理、数据库、回测、执行、容量、监控和模型治理纳入同一体系。
- **面向 AI 原生研究：** 区分机器学习、端到端模型、LLM 与 Agent 的角色，并介绍 Vibe Coding 的正确使用边界。
- **强调可验证性：** 任何策略都应经过数据审计、样本外检验、成本建模、风险分析和可复现实验。

## 适合读者

- 希望系统进入量化投资领域的学习者；
- 从事股票、期货、基金、固收或衍生品研究的投资者；
- 希望把统计学习、机器学习或 LLM 用于金融研究的开发者；
- 需要建设研究平台、回测系统和数据基础设施的量化团队；
- 希望形成跨资产、多策略投资框架的进阶实践者。

## 推荐阅读路径

### 基础路径

依次阅读第1—5章，建立量化投资、资产定价、数据、统计、模型验证和市场微观结构的基本认识。

先选择第6—12章中的目标市场，再阅读第13—22章的策略方法，最后进入组合构建、风险和交易执行。

重点阅读第28—32章，建立从数据源、数据库、回测、编程环境到 LLM/Agent 研究工作流的完整链路。

第27章独立覆盖宏观经济、主要经济体政策、地缘政治、国际贸易、产业链、科技竞争、能源安全和跨境资本流动，并将这些变量映射到资产与风险情景。

建议按“第14章机器学习 → 第30章回测评估 → 第31章R/Python工具 → 第32章端到端模型、LLM、Agent与Vibe Coding”的顺序阅读。

## 项目结构

```text
.
├── README.md                  # 项目说明与全书目录
├── LICENSE                    # MIT许可证
├── markdown/                  # 按章节组织的Markdown书稿
├── images/                    # 插图与图表资源
├── code/                      # 与章节对应的示例代码
├── data/                      # 示例数据与数据字典
├── script/                    # 电子书构建脚本
├── .github/workflows/         # GitHub Pages自动部署
└── dist/                      # 本地构建产物，不纳入版本控制
```

章节、代码、数据和图片建议使用相同的两位数字前缀。例如，第14章的配套材料分别放在 `markdown/14-...md`、`code/14-machine-learning/`、`data/14-machine-learning/` 和 `images/14-machine-learning/`。

## 构建电子书

构建环境需要 Python 3.10+ 和 Pandoc 3.x。默认生成单文件HTML和EPUB：

```bash
python script/build_book.py
```

只生成一种格式：

```bash
python script/build_book.py --format html
python script/build_book.py --format epub
```

产物输出到 `dist/`。构建顺序直接读取本README中的全书目录，因此调整章节后无需再维护第二份章节清单。

### 构建GitHub Pages电子书

生成带章节侧栏、前后翻页、移动端布局和EPUB下载的多页网站：

```bash
python script/build_site.py
```

网站输出到 `dist/site/`，入口为 `dist/site/index.html`。仓库中的 `.github/workflows/pages.yml` 会在推送到默认分支后自动构建并部署GitHub Pages，无需把 `dist/` 提交到Git。请在GitHub仓库的 **Settings → Pages → Build and deployment** 中将发布源设置为 **GitHub Actions**。

本地预览：

```bash
python -m http.server 8000 --directory dist/site
```

然后访问 `http://localhost:8000/`。

书稿和电子书不需要放在两个长期分支：建议以 `main` 作为唯一默认分支保存Markdown、脚本和资源，网页由GitHub Actions生成并作为Pages构建产物发布。
